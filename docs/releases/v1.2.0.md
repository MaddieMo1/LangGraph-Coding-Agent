# LangGraph Coding Agent v1.2.0

状态：Stable。v1.2.0 收录已完成真实环境验收的 Day19 Unity Worker 能力，在 v1.1.0 的需求契约、人工审批、审计、只读观察和本地 Git 所有权边界上，增加不可变快照、隔离执行以及独立 EditMode/PlayMode 门禁。

## 不可变 Unity 作业

- 控制器只把 `Assets`、`Packages`、`ProjectSettings` 和已批准的生成源码/测试写入确定性 `.unityjob` 快照。
- 快照固定 Unity 版本、Package manifest、文件列表、大小和 SHA-256；拒绝链接、路径穿越、越界文件、超限输入和构建期间发生变化的源工程。
- compile、EditMode 和 PlayMode 使用同一快照但独立作业、尝试号、结果与历史，陈旧或错配结果不能进入 Reviewer 或 Git。

## 本机与 HTTPS Worker

- 本机模式只以固定参数启动 `python -m worker.unity_worker` 子进程，不接受任意可执行文件、Shell 命令或 Unity 参数。
- 远程模式只暴露固定 HTTPS 作业路由，使用时间戳、nonce、请求体摘要和专用凭据 HMAC 签名；非回环地址拒绝明文 HTTP。
- Worker 的 SQLite 元数据支持重启后的中断分类；取消、超时和完成路径均绑定精确作业并清理所属进程与沙箱。
- 结果和白名单产物在控制器接受前均校验声明大小与 SHA-256，不确定提交不会回退到本机重复执行。

## 安全边界

- 默认 `network=disabled` 只有在操作系统、容器或虚拟机实际强制隔离并由 Worker 声明能力时才可执行。
- 远程 API 拒绝未授权、重放、陈旧、超大、非法快照、跨作业访问和非白名单产物请求。
- 调用方不能提交命令、环境变量、任意下载 URL、Git push/merge、部署操作或生产凭据。
- 本地控制台与 `/observe` 只投影脱敏 Worker ID、门禁、状态、耗时、测试计数和稳定错误码，不暴露凭据、源码、完整日志、绝对路径或 HMAC 材料。

## 兼容性

- Python 3.10+；离线 CI 与发布门禁使用 Python 3.11。
- 真实 Unity 验收使用 Unity `2022.3.62f2c1`；本机与远程模式共享版本 1 作业/结果契约。
- v1.1.0 及更早 checkpoint 可以安全读取和恢复，但没有独立 PlayMode 与当前快照证据时不能满足 v1.2.0 Git 门禁。
- 远程 Worker 为显式启用功能；未配置时继续使用本机模式，不会因远程提交不确定而静默切换执行位置。

## 验证证据

- Day19 专项测试 76 项通过；v1.2.0 发布分支完成 576 项完整 Python 回归（22.904 秒），合并后的 `main` 再次完成 576 项回归（24.489 秒），`compileall` 与 `git diff --check` 通过。
- 同一 34 文件不可变快照在隔离主机 `172.16.10.71` 上通过直接本机客户端和真实 HTTPS 两条路径；Unity compile 通过，EditMode 1/1、PlayMode 1/1 通过。
- Worker 的 Windows Firewall 保留控制器局域网通信并阻断公网 IPv4/IPv6；真实 HTTPS 使用本地 CA 证书，陈旧签名返回 `REQUEST_STALE`。
- 真实运行验证幂等取消并返回 `WORKER_CANCELLED`，所有成功门禁与取消探针均确认所属进程停止和沙箱删除。
- 下载的 `unity-evidence.json` 与 Worker 声明的大小和 SHA-256 一致；源 Unity 工程快照前后指纹一致。
- Reviewer 返回 100 分且无剩余问题；获批文件只提交到隔离生成代码仓库的任务分支，未执行远程 push、merge 或部署。

## 已知限制

- 当前远程身份使用单 Worker 专用预共享凭据，不是账号、OIDC、多租户或细粒度授权系统。
- SQLite 元数据和调度模型面向单 Worker 服务，不支持集群调度、弹性伸缩或跨节点租约。
- 网络隔离能力声明不能替代部署证据；新环境必须重新验证防火墙、容器或虚拟机策略。
- GitHub Actions 离线门禁不能替代真实 Unity、证书链、操作系统隔离或局域网远程 Worker 验收。
