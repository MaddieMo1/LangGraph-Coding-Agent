# v0.10.0 — Day13 Multi-Model Router

## 核心能力

- 为 Architecture、File Planner、Coder、Test Generator、Reviewer 和 Repair 接入统一的确定性多模型路由，不增加 Agent 数量。
- 按角色与 `simple`、`standard`、`complex` 复杂度选择 DeepSeek、Kimi、Qwen 或 GLM。
- 结构化输出不合法时先在当前模型进行一次格式纠正；仍不合法或 Provider 调用失败时，最多跨 Provider 回退一次。
- 将 Provider、模型、复杂度、选择原因、请求次数、耗时、token usage 和回退状态持久化到任务检查点，并在 UI 只读展示。
- 保持 Day11 人工审批、Unity 隔离验证和 Day12 Git 安全边界不变。

## 验收修正

- File Planner 对明确的单文件请求实施确定性文件范围约束，避免模型扩展未授权文件。
- Reviewer 在编译和测试成功后只评价本次批准文件，不再把既有项目基线问题误判为当前任务缺陷。
- Repair 原因卡片移除 Gradio 默认白色底板，保持深色主题一致。
