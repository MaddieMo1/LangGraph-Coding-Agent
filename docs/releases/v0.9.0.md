# LangGraph Coding Agent v0.9.0

## Day12：安全本地 Git Agent

- 在代码生成前验证 Git 仓库、提交身份、基线提交和干净工作区，并为任务创建独立的 `agent/<id>` 本地分支。
- 仅暂存人工批准且内容哈希未漂移的文件；静态检查、Unity 编译、EditMode 测试和 Reviewer 全部通过后才创建本地提交。
- Git 工具采用结构化接口，不开放任意命令，不执行 push、PR、merge、rebase、reset 或历史改写。
- 用户可显式将失败现场保存到包含未跟踪文件的 Git stash，并在安全清理工作区后开始新任务。

## 可恢复工作流

- 单活动任务锁阻止重复发起任务，并支持刷新后继续原 thread、原分支和已批准文件。
- 失败任务支持重新生成测试、重新检查 Unity 基线和重新修复当前任务，无需从头生成生产代码。
- Repair 复审显示修复轮次、审批序号、失败门禁、错误代码、根因、关联文件与修复策略。

## 任务中心与 UI

- 新增“工作台 / 任务中心”双视图，并保留顶部实时运行状态、任务 ID 与提案来源。
- 提供全部、进行中、需要处理、已完成四类统计，支持搜索、状态筛选、每页 10 条任务、详情抽屉和非活动任务批量删除。
- 活动任务置顶并受运行时安全锁保护；删除历史只作用于选中的 SQLite checkpoint/write 记录。
- 统一深色加载骨架、悬浮状态、可滚动 Diff、Repair 原因卡以及等高、同排、与任务卡对齐的筛选控件。
