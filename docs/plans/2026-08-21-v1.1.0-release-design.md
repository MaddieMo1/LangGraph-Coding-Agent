# v1.1.0 正式发布设计

## 发布定位

`v1.1.0` 是基于 `v1.0.0` 的向后兼容功能版本，收录已经合并、验证并投入本机运行的 Day16～Day18 能力：Unity API 可信知识检索、审批审计与本地权限控制、团队只读观察。它不改变现有工作流 checkpoint 协议，不包含账号/SSO、多节点部署或 PlayMode 扩展。

## 发布产物

- `project_version.py` 更新为 `1.1.0`，继续作为 UI 版本号的单一来源。
- README 版本徽章更新为 `v1.1.0`，新增 v1.1.0 汇总与发布说明链接；历史版本章节保持不变。
- 新增 `docs/releases/v1.1.0.md`，覆盖新增能力、安全边界、兼容性、验证证据和已知限制。
- 从最终发布提交创建带说明的 `v1.1.0` Git Tag，并用同一发布说明创建 GitHub Release；不上传本地配置、数据库、日志或密钥。

## 验收门禁

1. 版本单元测试确认 `project_version.py`、README 徽章和 UI 标题共享 `1.1.0`。
2. 发布说明测试确认 Day16～Day18、安全边界、兼容性、489 项回归和真实手机验收均被记录。
3. 完整 Python 回归、`compileall`、`git diff --check` 和环境预检通过。
4. 发布分支与 `main` 推送成功，Tag 指向最终 `main` 发布提交。
5. GitHub Release 标题、Tag、目标提交和正文经远程 API 复核。
