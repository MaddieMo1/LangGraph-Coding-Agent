# v1.1.0 Release Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 将已验收的 Day16～Day18 能力作为 LangGraph Coding Agent v1.1.0 正式发布到 GitHub。

**Architecture:** 保持 `project_version.py` 为版本单一来源，README 和发布说明只引用该发布版本的稳定证据。先在发布分支完成文件与测试，再合并 `main`，最后从同一提交创建 Tag 与 GitHub Release。

**Tech Stack:** Python、unittest、Git、GitHub CLI、Markdown

**Files:**
